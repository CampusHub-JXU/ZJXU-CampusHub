## 更新日志

版本 `v0.13.6` 合并了社区贡献的反馈系统、宿舍电费趋势分析与体测成绩计算器，并完成了相关页面 UI 重构、权限中心整合与多处交互优化。

### 变更内容

- **免登录问题反馈**：新增应用内「问题反馈」页面，通过轻量中转服务将反馈直接提交为公开仓库 GitHub Issue，支持截图/日志附带与状态提示。
- **宿舍电费趋势与历史**：新增宿舍用电趋势分析与历史用电记录视图，支持直观查看近期电量变化与日均消耗。
- **体测成绩计算器**：新增体测成绩计算器并融入体测页面，支持按年级与性别实时测算单项得分、总分及评定等级。
- **权限中心与设置优化**：新增「权限中心」统一查看并引导配置通知、日历等系统权限；优化桌面小组件背景设置与设置搜索体验。
- **欢迎页与服务大厅优化**：调整欢迎页标题为「欢迎使用嘉兴大学 · CampusHub」；移除服务大厅右上角历史微信跳转按钮，顶部导航保留回到首页图标。

### 验证与范围

- `flutter analyze` 与相关模块测试（反馈、电费、体测、设置、权限、欢迎页、服务大厅等 451 项用例）通过。
- 已在真机（Android）安装 Debug 包实测欢迎页、服务大厅、体测计算器、电费分析与权限中心页面。

### 安装说明

- 可以在应用内直接更新，也可以从 Release 页下载对应架构的官方 APK 覆盖安装。
- 请不要先卸载旧版，应用数据会保留。如果系统拒绝覆盖安装，请停止安装，并反馈版本号和机型。
